# ONGAKU MEDIA — descargas

Reproductor de música y video. Aquí se publica cada versión nueva.

- **Celular (Android):** [ONGAKU-MEDIA.apk](https://github.com/elpalaciodelatransmision-cyber/ongaku-media-descargas/releases/latest/download/ONGAKU-MEDIA.apk)
- **PC (Windows):** [Instalar-ONGAKU-MEDIA.exe](https://github.com/elpalaciodelatransmision-cyber/ongaku-media-descargas/releases/latest/download/Instalar-ONGAKU-MEDIA.exe)

ONGAKU revisa este repositorio (`version.json`) para avisar cuando hay una versión nueva.
